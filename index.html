Mode démo local

Les onglets de ce navigateur partagent le salon.

Pour jouer entre plusieurs téléphones, reliez GEOHUNT à votre projet Supabase. Les positions et les statuts passent par un canal Realtime public ; aucune table n'est nécessaire.

OU

Utilisez uniquement la clé anon/publishable. Ne placez jamais une clé service_role dans une application web. Si l'autorisation Realtime est active sur votre projet, autorisez broadcast et presence pour le rôle anon.
